# Spec: Update homepage title to "Agentic SLDC"

- Issue: #15
- Status: draft
- Date: 2026-09-02

## Objective

Replace the default `create-next-app` document `<title>` ("Create Next App")
with "Agentic SLDC" so that visitors see the correct branded browser tab
title. Success means the rendered document title (verified through
`document.title`/the `<title>` element) reads exactly "Agentic SLDC" on the
homepage.

## Tech Stack

- Next.js 16.3.1 (App Router), React 19.2.8 / react-dom 19.2.8
- TypeScript 5, strict mode (`tsconfig.json`)
- Tailwind CSS 4, ESLint 9 with `eslint-config-next`
- Package manager: pnpm 10.33.0
- `@playwright/test` is already installed as a devDependency, with
  `playwright.config.ts` at the repo root and specs in `e2e/`
  (`e2e/counter.spec.ts` exists as the current example).

## Commands

- Install dependencies: `pnpm install`
- Dev server: `pnpm dev`
- Build: `pnpm build`
- Start (production): `pnpm start`
- Lint: `pnpm lint`
- Type check: `pnpm exec tsc --noEmit`
- End-to-end tests: `pnpm exec playwright test`
- Focused end-to-end test for this change:
  `pnpm exec playwright test e2e/title.spec.ts`

## Project Structure

- `app/layout.tsx` — root layout; exports the `metadata` object
  (`export const metadata: Metadata = { title: "Create Next App", ... }`)
  consumed by Next.js's App Router to render the `<title>` tag. This is the
  only place the title needs to change.
- `e2e/` — Playwright end-to-end specs; this change adds `e2e/title.spec.ts`.
- `playwright.config.ts` — existing Playwright configuration (webServer,
  testDir `e2e`); no changes needed.

## Code Style

Existing metadata declaration in `app/layout.tsx`:

```tsx
export const metadata: Metadata = {
  title: "Create Next App",
  description: "Generated by create next app",
};
```

Convention: metadata is a typed, statically-exported `Metadata` object edited
directly; no dynamic title generation is used elsewhere in the app.

## Testing Strategy

- Test level: end-to-end (browser-driven), consistent with the existing
  Playwright suite (`e2e/counter.spec.ts`) already used for homepage
  behavior checks in this repository.
- Location: `e2e/title.spec.ts`.
- RED: before the change, run
  `pnpm exec playwright test e2e/title.spec.ts` — it MUST fail because the
  page title is still "Create Next App".
- GREEN: after the change, the same command MUST pass, asserting
  `await expect(page).toHaveTitle("Agentic SLDC")` on the homepage (`/`).
- Full suite command: `pnpm exec playwright test` (must still pass, including
  the pre-existing `e2e/counter.spec.ts`).
- Manual/complementary checks (do not replace the e2e test): `pnpm lint`,
  `pnpm exec tsc --noEmit`, `pnpm build`.

## Boundaries

- Always: change only the `title` field in `app/layout.tsx`'s `metadata`
  export; keep the existing `description` field unless the issue asks
  otherwise (it does not).
- Ask first: any request to change the title differently per-route/page
  (e.g. per-page metadata overrides) — not required by this issue.
- Never: modify unrelated metadata (favicon, `description`, Open Graph tags)
  or unrelated homepage content/behavior (e.g. the counter button feature).

## Technical Design

- R1: `app/layout.tsx`'s exported `metadata.title` MUST be the string
  `"Agentic SLDC"` (matching the issue's requested title verbatim), replacing
  `"Create Next App"`.
- R2: No other fields in `metadata` or other files change.
- R3: The rendered `<title>` element on the homepage (`/`) MUST equal
  "Agentic SLDC", verifiable via Playwright's `page.title()` /
  `toHaveTitle` assertion.

## Success Criteria

- `app/layout.tsx` exports `metadata.title === "Agentic SLDC"` (R1).
- `pnpm exec playwright test e2e/title.spec.ts` passes, asserting the
  homepage document title is exactly "Agentic SLDC" (R3).
- `pnpm exec playwright test` (full suite), `pnpm lint`,
  `pnpm exec tsc --noEmit`, and `pnpm build` all succeed.
